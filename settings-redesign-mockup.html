How to set up SMTP — step by step
Gmail (free, recommended)
  1. Turn on 2-Step Verification: myaccount.google.com → Security.
  2. Search "Google App passwords" → create one for Mail.
  3. Host smtp.gmail.com · Port 587 · SSL off (auto) · username = your Gmail.
Outlook / Microsoft 365
  1. Host smtp.office365.com · Port 587 · SSL off (auto) · app password if 2FA.
Any provider
  1. Port 465 = SSL on · 587 = SSL off (STARTTLS) — the toggle follows the port; Test auto-corrects.
